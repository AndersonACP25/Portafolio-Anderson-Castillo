# Icon sources

New monochrome technology icons use Simple Icons 16.35.0 (CC0), with a light fill for the dark portfolio background: https://simpleicons.org/. Project license included in SIMPLE-ICONS-LICENSE.txt. Individual brand rights remain with their respective owners.

VS Code uses the Devicon original SVG: https://github.com/devicons/devicon/blob/master/icons/vscode/vscode-original.svg. Devicon MIT license included in DEVICON-LICENSE.txt.

The generic AI and code symbols are original geometric SVG illustrations. Existing repository icons remain in use for Playwright, Postman, Java, C# and Azure DevOps.
